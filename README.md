# Nod Kurulum

Nod masaüstü uygulamasını n8n’e bağlamak ve OAuth erişimini doğrulamak için bağımsız bir Agent Skill. Kurulum, yerel ve uzak sunucu adresleri, hesap seçimi, izin kapsamları ve bağlantı sorunları için adımlar içerir.

A community Agent Skill for installing Nod Desktop, connecting it to n8n, and checking OAuth access. Copy this repository's skill directory as `nod-kurulum` into a skills location recognized by your agent. In Codex, invoke `$nod-kurulum`.
